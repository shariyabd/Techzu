3 · Branches: many local, one on GitHub

Task branches are scratch space on your machine. Every task joins the end of main as one unbroken block of commits, so the history stays linear.

main: linear history, never force-pushedtask branch: commits rebased locally before landing

4 · Anatomy of a commit

Required format (Conventional Commits)

feat(assignment): add atomic ticket claim with race tests

Claims use a conditional UPDATE so two agents
can never both own the ticket; the loser gets
a 409 instead of silently overwriting.

Refs: T06.1
Implements: TD-031, TD-050

Rules

  • Subject: type(scope): imperative summary, ≤ 72 characters, no trailing period
  • T06.1: atomic ClaimTicket …: no plan number in the subject
  • Plan traceability goes in the Refs: trailer: git log --grep "Refs: T06"
  • Co-Authored-By: …: no co-author or AI attribution, ever
  • One subtask per commit, tests and code together, and every commit passes the gate
  • Review fixes are folded in with autosquash, so there are no "address review" commits
