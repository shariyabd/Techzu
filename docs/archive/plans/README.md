# Archive: AI execution plans

These files are the **historical execution plans** the project was built from with AI coding agents: `ROADMAP.md` (the execution rules and plan order) and `P1`–`P6`, `P8` (one plan per phase, split into waves of parallel subtasks).

They are process artifacts, kept for transparency about how the work was organised. They are **not** a description of the current system: later work changed many details, and some file paths inside them point at the old documentation layout (`PRD.md`, `TECHNICAL_DECISIONS.md`, `docs/DESIGN.md`, `docs/FEATURES.md`, `docs/plans/`).

For the system as it is now, read [docs/README.md](../../README.md). The process itself is described in TD-140 of the [decision log](../../11-technical-decisions.md) and pictured in [the workflow diagram](../../diagrams/workflow.html).
